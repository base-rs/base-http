# io_uring readiness evidence — Hana, 2026-10-27

See the [results and implementation](../../uring-readiness/readme.md). Final scheduler commit: `587e74620d1dc1468a588f02b7ea1fd37b722db7`, parent main `f05a630db60686526b6145efb284a9c2f61fe8b4`.

- `confirmation/`: 80 uninstrumented echo samples, five rounds of four backends × two connection counts × two payloads. One-second warmup and four-second measurement.
- `headroom/`: 24 uninstrumented echo samples, three rounds at 64 connections, three client workers on three physical cores. Compare within each placement cohort.
- `http-raw/`, `http/`: twelve samples each, three rounds at 64 connections, one-second warmup and three-second measurement. The raw Tokio control is spawned; full Hyper uses the runtime root. Rust protocol/application sources are identical between before and after. A failed invocation of an unavailable Hyper mode was excluded; the complete HTTP matrix uses the supported `hyper-tokio` mode.
- `counts-final/`: sixteen separate instrumented echo samples. Counts normalize by total received bytes/payload size, including warmup and boundary echoes. The interposer cannot observe ring operations. Instrumented rates are not throughput evidence.
- `validated-summary.json`: complete-matrix validation and paired throughput ratios. All echo clients validate every byte, exit successfully and have empty stderr. HTTP samples pass the response probe and report no `wrk` socket/status errors. HTTP server logs contain peer-reset reports as the load generator closes connections; three raw logs end within such a report when the runner terminates the server. The validator checks complete lines and records those partial tails.
- `screen/`, `counts/`, `exploratory-profiles/`, `after.gz`: exploratory evidence from the initial candidate before the final clarifying source formatting. The profile text/stat reports and frozen exploratory executable are retained separately; final performance conclusions use `confirmation`, `headroom`, `http-raw`, `http` and `counts-final`.
- `before.gz`, `after-final.gz`: frozen original and final echo executables. Every final echo client uses `before`. `http-before.gz` and `http-after.gz` are the frozen HTTP executables. `binary-sha256.json` hashes decompressed bytes; timing executables have no LLVM profile-data sections. `wrk-sha256.json` records the fixed HTTP load generator.
- `scheduler.patch`: complete local scheduler commit. Apply it to the [pinned clean archive](../../../hello/results/layer-breakdown-20261027/scheduler.tar.gz), SHA-256 `4b14724b65b2da5ca0d7b5cf95823b9ae646b1a4cfab5eb8ceadff6df1a871e5`.
- `echo-sources.tar.gz`: the identical native-epoll echo extension, plus workspace manifest and lockfile. Overlay on clean main for the baseline or on the patched scheduler for the fix. `http-sources.tar.gz` contains both HTTP build trees and dependency patches; relocate their scheduler paths when changing the recorded root directory.
- `source-checks.json`, `expected-scheduler-sha256.json`: all 525 selected source/manifest files match the final committed fix. The eight changes against clean main are exactly the committed implementation, tests, design/readme and release-note files. Before/after HTTP Rust sources match. No private scheduler or Tokio benchmark hooks are used in the final HTTP builds.
- `original-checkout-checks.json`: original scheduler's 26 pending-file hashes are preserved; both the old OOB worktree and new fix worktree are clean.
- `coverage-final.log`, `coverage-final.json.gz`: shared Bake coverage task and LLVM function/region export. Production coverage passes 7,531/7,531 regions, automatically excluding three existing invariant-only `unreachable!()` regions. The suite executes both OOB modes, 231 unit tests, 276 shared conformance cases, and the bound-I/O/resource/pool/process tests. Existing ignored test helpers remain governed by the suite.
- `coverage-unfiltered.log`: the first shared task could not read Hana's missing Rust standard-library debug source. The successful final invocation uses `LLVM_COV_FLAGS='--ignore-filename-regex=(/usr/src/debug/rust|/tests/|/tests.rs|_tests.rs)'`; test executables still run, while the region gate measures production source. This does not claim complete test-source coverage.
- `clippy.log`, `echo-tests.log`, `build-final.log`, `http-*-build.log`: clean lint/build and six unit/thirteen integration echo checks. Compilation, coverage, profiling and throughput phases do not overlap.
- `run.py`, `http-run.py`, `summarize-followup.py`, `summarize-echo.py`, `profile.py`: exact orchestration tools. To revalidate this directory, run `python3 summarize-followup.py . --validator summarize-echo.py`.
- `sha256.json`: every other evidence file's checksum.

The initial screen is superseded by the final confirmation, rather than pooled with it. Echo CPU accounting covers whole process lifetimes, not just the timed window. These are loopback closed-loop workloads; they do not isolate server capacity or establish physical-network, owned/multishot payload, multi-worker scaling, or general backend superiority.
